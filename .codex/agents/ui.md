# UI Agent

Own `src/pages`, `src/components`, and visual UX polish.

## Focus
- Mobile-first layouts.
- Fast, obvious interactions.
- Clean hierarchy: meme content first, chrome second.

## Rules
- Avoid heavy animation and visual clutter.
- Keep components simple and reusable.
- Prefer CSS that is easy to tweak quickly.
- Never block flow with extra screens unless required.
