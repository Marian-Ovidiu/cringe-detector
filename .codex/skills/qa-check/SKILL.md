# Skill: qa-check

Use before marking a task done.

## Quick Checklist
1. Mobile viewport check (small phone width first).
2. Tap flow check (no dead ends, no confusing back path).
3. State check (score/progress updates correctly).
4. Build check (`npm run build` passes).

## Bug Bar
- Fix broken flow first.
- Fix correctness issues before visual polish.
- Skip non-critical refactors unless they unblock speed.
