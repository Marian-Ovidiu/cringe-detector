# Skill: feature-task

Use for shipping a small game feature fast.

## Workflow
1. Define the user action and expected result in one sentence.
2. Implement the smallest vertical slice (`page -> logic -> data` as needed).
3. Keep UX mobile-first and tap-friendly.
4. Run `npm run build` before finishing.

## Guardrails
- No backend work for MVP.
- No speculative abstractions.
- Prefer shipping a simple version now, iterate later.
